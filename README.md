# Encrypt Everything promo site

Static promo site for [Encrypt Everything](https://github.com/xAlisher/encrypt-everything-android), based on the supplied Figma design.

## Preview

Open `index.html` directly, or run:

```sh
python3 -m http.server 8080
```

Then visit <http://localhost:8080>.

## Design

- Black canvas
- White supplied wordmark and portrait artwork
- Accent: `#FF0178`
- Responsive single-screen hero

The site is intentionally dependency-free and deploys directly through GitHub Pages.
